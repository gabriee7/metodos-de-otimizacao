CONCEITO Heurística × Meta-heurística

Uma heurística é um procedimento específico para um problema, que busca uma solução boa (não necessariamente ótima) em tempo razoável — ex.: uma regra gulosa de construção. Uma meta-heurística é um framework genérico de busca, aplicável a várias classes de problemas, que orquestra heurísticas (construtivas, de vizinhança) com estratégias de escape de ótimos locais — ex.: Simulated Annealing, GRASP, Algoritmos Genéticos.

Ponto de atenção: uma busca local "melhor melhora" ou "primeira melhora" sozinha é heurística, não meta-heurística — ela fica presa no primeiro ótimo local. Meta-heurísticas envolvem algum mecanismo de diversificação (aceitar piora, reiniciar, perturbar) para escapar disso.
