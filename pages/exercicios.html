P1 — Caixeiro Viajante (TSP)

Objetivo da prova: modelar o TSP em C — leitura de instância, struct de solução, escrita de solução e função objetivo com penalização (peso α = 100 para cidades repetidas ou não visitadas). Instância: matriz de custos n×n, formato dado abaixo.

n c11 c12 c13 ... c1n c21 c22 c23 ... c2n ... cn1 cn2 cn3 ... cnn
Pontos de atenção desta prova: zerar valor_objetivo no início de calcular_funcao_objetivo (senão acumula entre chamadas); a rota é um ciclo — não esquecer a aresta de volta da última cidade para a primeira; a função de escrita e a de cálculo da FO recebem a solução por referência e retornam void, como exige o enunciado; dimensionar os vetores com #define para o limite de 200 cidades, sem alocação dinâmica.
Q1 · 0,5 Leitura da instância

Lê o número de cidades e a matriz de custos de um arquivo texto, recebendo o nome/diretório do arquivo por parâmetro. Os dados ficam em variáveis globais, como exige o enunciado — evita passar a instância inteira por parâmetro em toda função.

void ler_instancia(const char *nome_arquivo) { FILE *arquivo = fopen(nome_arquivo, "r"); if (arquivo == NULL) { printf("Erro ao abrir o arquivo de instancia: %s\n", nome_arquivo); exit(1); } fscanf(arquivo, "%d", &numero_cidades); for (int i = 0; i < numero_cidades; i++) for (int j = 0; j < numero_cidades; j++) fscanf(arquivo, "%f", &matriz_custos[i][j]); fclose(arquivo); }
Q2 · 0,5 Struct de solução

A solução do TSP é a rota (permutação das cidades) e o valor da função objetivo correspondente. rota[k] guarda a cidade visitada na k-ésima posição.

#define MAXIMO_CIDADES 200 #define PESO_PENALIDADE 100 extern int numero_cidades; extern float matriz_custos[MAXIMO_CIDADES][MAXIMO_CIDADES]; typedef struct tSolucao { int rota[MAXIMO_CIDADES]; float valor_objetivo; } Solucao;
Q3 · 0,5 Escrita da solução

Escreve a FO e a rota na tela e em arquivo, recebendo a solução por referência.

void escrever_solucao(Solucao &s, const char *nome_arquivo) { printf("Valor da FO: %.2f\n", s.valor_objetivo); printf("Rota: "); for (int k = 0; k < numero_cidades; k++) printf("%d ", s.rota[k]); printf("\n"); FILE *arquivo = fopen(nome_arquivo, "w"); if (arquivo == NULL) return; fprintf(arquivo, "Valor da FO: %.2f\n", s.valor_objetivo); fprintf(arquivo, "Rota: "); for (int k = 0; k < numero_cidades; k++) fprintf(arquivo, "%d ", s.rota[k]); fprintf(arquivo, "\n"); fclose(arquivo); }
Q4 · 1,0 Função objetivo com penalização

Soma o custo de percorrer o ciclo completo (incluindo a volta da última cidade para a primeira) e penaliza, com o mesmo peso α = 100, cada cidade nunca visitada e cada visita repetida além da primeira.

void calcular_funcao_objetivo(Solucao &s) { s.valor_objetivo = 0.0f; int quantidade_visitas[MAXIMO_CIDADES]; for (int i = 0; i < numero_cidades; i++) quantidade_visitas[i] = 0; for (int k = 0; k < numero_cidades; k++) { int cidade_atual = s.rota[k]; int proxima_cidade = s.rota[(k + 1) % numero_cidades]; s.valor_objetivo += matriz_custos[cidade_atual][proxima_cidade]; quantidade_visitas[cidade_atual]++; } for (int i = 0; i < numero_cidades; i++) { if (quantidade_visitas[i] == 0) s.valor_objetivo += PESO_PENALIDADE; else if (quantidade_visitas[i] > 1) s.valor_objetivo += PESO_PENALIDADE * (quantidade_visitas[i] - 1); } }
Verificação por segundo caminho (instância toy, 5 cidades):

Rota viável 0-1-2-3-4-0: custo manual 10+35+30,5+22+10 = 107,50 — bate com a saída do programa.

Rota inviável 0-1-1-3-3-0 (cidade 1 e 3 repetidas, cidades 2 e 4 nunca visitadas): custo de arestas 55,3 + 4×100 de penalidade = 455,30 — bate.

Pegadinha comum: usar % (módulo) para fechar o ciclo — rota[(k+1) % numero_cidades] — em vez de tratar a última aresta como caso especial separado; os dois funcionam, mas esquecer completamente a aresta de volta (tratar a rota como caminho aberto, não ciclo) é o erro mais comum aqui.

P2 — Problema da Mochila (PM)

Objetivo: selecionar o subconjunto de itens que maximize o valor total sem exceder a capacidade da mochila. Mesma estrutura de solução do TSP (struct + leitura de instância em globais + escrita + FO por referência), mas sem sequência e sem ciclo — a solução é um vetor binário de escolha, não uma ordem de visita. Instância: número de itens e capacidade na primeira linha, depois uma linha "valor peso" por item.

n c v1 p1 v2 p2 ... vn pn
O que muda em relação ao TSP: a FO aqui é para maximizar (não minimizar); não existe matriz de custo entre pares, só valor/peso por item; não existe "cidade não visitada" — a penalidade é por estourar a capacidade, proporcional ao excedente de peso (ALFA × excedente), não um valor fixo por violação.
Q1 · leitura Leitura da instância

Lê o número de itens e a capacidade na primeira linha, depois valor e peso de cada item, guardando tudo em variáveis globais — mesmo padrão do TSP (ler_instancia recebe só o caminho do arquivo por parâmetro).

int numero_itens; int capacidade_mochila; int matriz_valor_peso_itens[MAX_OBJ + 1][2]; void ler_instancia(char* arq) { FILE* f = fopen(arq, "r"); fscanf(f, "%d %d", &numero_itens, &capacidade_mochila); for (int i = 1; i <= numero_itens; i++) fscanf(f, "%d %d", &matriz_valor_peso_itens[i][0], &matriz_valor_peso_itens[i][1]); fclose(f); }
Ponto de atenção: a matriz aqui é n×2 (valor, peso), não n×n como no TSP — não confundir os dois formatos de instância na hora de escrever o fscanf.
Q2 · struct Struct de solução

A solução é um vetor binário: vet_obj[i] = 1 se o item i foi escolhido, 0 caso contrário — não uma permutação como no TSP.

#define MAX_OBJ 50 typedef struct TSolucao { int vet_obj[MAX_OBJ + 1]; int fo; } Solucao;
Q3 · escrita Escrita da solução

Mesma técnica do TSP: um único parâmetro de arquivo decide tela vs. arquivo.

void escrever_solucao(Solucao &sol, char* arq) { FILE* f = (strcmp(arq, "") == 0) ? stdout : fopen(arq, "w"); fprintf(f, "FO: %d\n", sol.fo); for (int i = 1; i <= numero_itens; i++) fprintf(f, "%d ", sol.vet_obj[i]); if (strcmp(arq, "") != 0) fclose(f); }
Q4 · FO Função objetivo com penalização por capacidade

Soma valor e peso só dos itens selecionados; se o peso total passar da capacidade, desconta ALFA vezes o excedente do valor acumulado.

#define ALFA 10 void calcular_FO(Solucao &sol) { sol.fo = 0; int peso_mochila = 0; for (int i = 1; i <= numero_itens; i++) { if (sol.vet_obj[i] == 1) { sol.fo += matriz_valor_peso_itens[i][0]; peso_mochila += matriz_valor_peso_itens[i][1]; } } if (peso_mochila > capacidade_mochila) sol.fo -= (peso_mochila - capacidade_mochila) * ALFA; }
Verificação manual (instância com capacidade 15):

Itens 1, 3, 5 (valores 10+15+30=55, pesos 4+8+6=18): peso excede em 3 → FO = 55 − 3×10 = 25 — bate com a saída do programa.

Itens 2, 4, 5 (valores 20+2+30=52, pesos 5+3+6=14): dentro da capacidade, sem penalidade → FO = 52.

Pontos de atenção: zerar sol.fo e o acumulador de peso no início da função (senão acumula entre chamadas); a penalidade é proporcional ao excedente (ALFA × excedente), diferente do TSP onde era um valor fixo (ALFA) por cidade problemática — não confundir os dois modelos de penalidade na hora de generalizar para outro problema.

P3 — Problema da Mochila Múltipla (PMM)

Objetivo: distribuir um conjunto de itens em múltiplas mochilas, cada uma com sua própria capacidade, maximizando o valor total dos itens guardados. É a generalização da Mochila simples (P2) para m mochilas — mesma estrutura de código (leitura em globais, struct + FO por referência), com a solução e a checagem de capacidade adaptadas para lidar com várias mochilas em vez de uma só.

n m cap1 cap2 ... capm v1 p1 v2 p2 ... vn pn
O que muda em relação ao PM (mochila única): a instância ganha uma linha a mais com as m capacidades; a solução deixa de ser binária — cada item guarda em qual mochila foi colocado (0 = nenhuma); e a checagem de excedente de peso/penalidade passa a ser feita por mochila, não uma vez só para o problema inteiro.
Q1 · leitura Leitura da instância

Lê n e m, depois o vetor com as m capacidades, e por fim valor/peso de cada um dos n itens — uma leitura a mais no meio, comparado ao PM.

int numero_itens; int numero_mochilas; int vet_capacidade_mochilas[MAX_MOCHILAS + 1]; int matriz_valor_peso_itens[MAX_ITENS + 1][2]; void ler_instancia(char* arq) { FILE* f = fopen(arq, "r"); fscanf(f, "%d %d", &numero_itens, &numero_mochilas); for (int k = 1; k <= numero_mochilas; k++) fscanf(f, "%d", &vet_capacidade_mochilas[k]); for (int i = 1; i <= numero_itens; i++) fscanf(f, "%d %d", &matriz_valor_peso_itens[i][0], &matriz_valor_peso_itens[i][1]); fclose(f); }
Ponto de atenção: a ordem de leitura importa — as capacidades vêm antes dos itens no arquivo. Trocar a ordem faz o fscanf ler capacidade como se fosse valor/peso de item, e o programa "funciona" sem travar, só com números errados.
Q2 · struct Struct de solução

No PM, vet_obj[i] era 0 ou 1. Aqui, vet_obj[i] guarda qual mochila recebeu o item — 0 (não usado) ou 1..m. Isso já garante sozinho que um item só pode estar em uma mochila por vez, sem precisar de checagem extra.

#define MAX_ITENS 50 #define MAX_MOCHILAS 10 typedef struct TSolucao { int vet_obj[MAX_ITENS + 1]; // vet_obj[i] = mochila do item i (0 = nao usado) int fo; } Solucao;
Q3 · escrita Escrita da solução

Mesma técnica de sempre: um parâmetro de arquivo decide tela vs. arquivo. Imprime a FO e, para cada item, o índice da mochila em que ele foi colocado.

void escrever_solucao(Solucao &sol, char* arq) { FILE* f = (strcmp(arq, "") == 0) ? stdout : fopen(arq, "w"); fprintf(f, "FO: %d\n", sol.fo); for (int i = 1; i <= numero_itens; i++) fprintf(f, "%d ", sol.vet_obj[i]); if (strcmp(arq, "") != 0) fclose(f); }
Q4 · FO Função objetivo com penalização por mochila

Em vez de um único acumulador de peso (como no PM), agora existe um vetor de pesos, um por mochila. Depois de somar valor/peso por item na mochila em que ele foi colocado, um segundo laço percorre as m mochilas comparando cada uma com sua própria capacidade.

#define ALFA 10 void calcular_FO(Solucao &sol) { sol.fo = 0; int vet_peso_mochilas[MAX_MOCHILAS + 1]; memset(vet_peso_mochilas, 0, sizeof(vet_peso_mochilas)); for (int i = 1; i <= numero_itens; i++) { int mochila = sol.vet_obj[i]; if (mochila != 0) { sol.fo += matriz_valor_peso_itens[i][0]; vet_peso_mochilas[mochila] += matriz_valor_peso_itens[i][1]; } } for (int k = 1; k <= numero_mochilas; k++) { if (vet_peso_mochilas[k] > vet_capacidade_mochilas[k]) sol.fo -= (vet_peso_mochilas[k] - vet_capacidade_mochilas[k]) * ALFA; } }
Verificação manual (instância com 2 mochilas, capacidades 15 e 20):

Itens 1,3 na mochila 1 (valor 25, peso 9 ≤ 15) e itens 2,5 na mochila 2 (valor 55, peso 20 = capacidade, sem exceder): FO = 25 + 55 = 80, sem penalidade em nenhuma mochila.

Mesma distribuição, mas item 6 também na mochila 2 (peso vira 22 > 20, excedente 2): FO = 85 − 2×10 = 65 — só a mochila 2 é penalizada.

Pontos de atenção: a comparação de excedente é > (estrito) — peso exatamente igual à capacidade não é excedente, é caso de fronteira que costuma pegar quem usa >= por engano. E como cada mochila tem seu próprio desconto, é possível ter várias mochilas excedidas ao mesmo tempo — o laço final soma o desconto de todas elas na FO, não só da primeira que encontrar.
