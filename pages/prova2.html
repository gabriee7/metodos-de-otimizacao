PRCP Rotulação Cartográfica (Turma 2025)

Objetivo: Escolher 1 posição dentre m opções para cada ponto, minimizando conflitos.

A solução gulosa implementada alcançou 17 pontos livres na instância de teste (i25.txt), enquanto a aleatória conseguiu apenas 5. A estratégia gulosa utilizou a contagem de conflitos marginais com pontos já fixados no mapa.
void heuristica_construtiva_gulosa(Solucao& s) { for (int i = 0; i < num_pts; i++) { int melhor_pos = 0, min_conflitos = 999999; for (int p = 0; p < num_pos; p++) { int qtd_conf = avaliar_conflitos_parcial(s, i, p); if (qtd_conf < min_conflitos) { min_conflitos = qtd_conf; melhor_pos = p; } } s.vet_sol[i] = melhor_pos; // Escolhe a melhor localmente } calcular_fo(s); }
sdTSP Caixeiro Viajante c/ Depósito Único (Turma 2026-1)

Objetivo: Visitar n cidades saindo e voltando de um depósito fixo, minimizando a distância percorrida.

Pegadinha estrutural: No sdTSP, o vetor de solução vet_rota não armazena o depósito, pois ele é implícito no início e fim. O tamanho do vetor é exato para as n cidades.
void gerar_solucao_vizinha(Solucao& s) { // Vizinhança Swap (Troca) - Escolhe 2 cidades e troca a ordem de visita int c1 = rand() % num_cidades; int c2; do { c2 = rand() % num_cidades; } while (c1 == c2); int temp = s.vet_rota[c1]; s.vet_rota[c1] = s.vet_rota[c2]; s.vet_rota[c2] = temp; calcular_fo(s); // Sem isso, nota zero! }
